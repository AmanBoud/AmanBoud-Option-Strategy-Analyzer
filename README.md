# Option-Strategy-Analyzer
This web-based Option Strategy Analyzer allows traders to visualize and evaluate multi-leg option strategies such as Straddles, Strangles, and Iron Condors. It helps intraday and positional option buyers and sellers better understand risk-reward scenarios with accurate profit/loss calculations.

## ⚙️ Features

- ✅ Create and analyze custom option strategies
- ✅ Real-time P&L calculation with spot price variation
- ✅ Color-coded profit (green) and loss (red) zones
- ✅ Visual graph representation of payoff chart
- ✅ Supports strategies like Straddle, Iron Condor, etc.
- ✅ Simple, user-friendly UI
- ✅ Built using React (frontend) and Node.js (backend)

## 🛠️ Tech Stack

- **Frontend**: React, Chart.js, TailwindCSS
- **Backend**: Node.js + Express
- **Optional**: Python (for deeper calculations)
